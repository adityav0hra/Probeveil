# Implementation phases and limitations

Phase 1 provides the durable control plane, real passive scanner, evidence, progress, scores and reports. Phase 2 adds browser/ZAP/Nuclei depth. Phase 3 adds automatically associated source, supply-chain, secret and infrastructure analysis. Phase 4 adds stateful and advanced protocol testing. Phase 5 adds full retest/review workflows, archives, Kubernetes and production operations.

Current limitations are displayed in reports: unauthenticated passive coverage cannot prove authenticated behaviour, active exploitation is not performed in Phase 1, and automated scanning cannot guarantee complete vulnerability discovery.
